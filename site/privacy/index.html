Privacy

Effective 5 September 2026

The CLI runs on your machine. It writes snapshots and reports only to paths you choose.

CLI data

The CLI passes your selected path to kubectl. It does not read or retain kubeconfig bearer tokens.

Collection uses read-only kubectl commands for RBAC objects, context, and Kubernetes version.

Reports can contain identity names, namespaces, groups, and access rules. Protect them under your own retention policy.

The CLI sends no telemetry and has no hosted cluster connection.

Website and demo data

The demo uses fixed fictional data in your browser. It does not upload matrices, snapshots, or reports.

Demo choices use session storage under the demo:kpe: prefix. Reset removes that demo state.

The site has no analytics, advertising trackers, third-party fonts, or third-party scripts.

License data

An existing license token and its last result are stored in local browser storage.

The token is sent over HTTPS only to the Sociobot verification endpoint. A cached result is checked at most once daily.

Clear this site’s browser storage to remove the token and result. License return URLs never enter the offline cache.

Field Kit sales are paused. This site collects no payment details.
