How it works

Create evidence in three steps

Each result remains attached to every rule and binding that grants it.

  1. 01

    Collect RBAC objects

    Fetch four RBAC object types and the Kubernetes version. Save a reusable snapshot.

    kpe snapshot --output rbac.json
  2. 02

    Ask bounded questions

    Name one subject and list the verbs, resources, namespaces, subresources, or URLs to check.

    --subject user:mina --matrix checks.json
  3. 03

    Export and verify

    Write Markdown and JSON. Sign the JSON and require your auditor’s trusted signer reference.

    evidence.md + evidence.json

Install

Build one inspectable Rust binary

Install from source, then run the bundled sample without kubectl or a cluster.

  • Uses a read-only kubeconfig for collection
  • Runs reports offline from a token-free snapshot
  • Marks aggregated ClusterRole results as uncertain

Limits and privacy

Know what the packet covers

The CLI evaluates collected Kubernetes RBAC objects. It does not model webhook, Node, or external identity-provider decisions.

Aggregated ClusterRole results include the server version and an uncertainty label.

The CLI sends no telemetry. The site has no analytics or third-party scripts.
